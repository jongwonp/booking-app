# 숙소 예약 웹앱 (MVP)

> 검색 → 가용성 확인 → 임시 홀드 → 예약 확정까지의 핵심 플로우를 빠르게 구현하고, 문서는 **핵심만 가볍게** 유지합니다.

---

## 1) 프로젝트 개요

- **목표**: 예약의 핵심 흐름(MVP)을 빠르게 구현하고 점진 개선
- **역할**: 게스트(사용자), 관리자
- **범위(MVP)**: 로그인/회원가입, 숙소 목록·상세, 달력 가용성, 임시 홀드(만료), 예약 확정, 마이페이지, 관리자(숙소/요금/차단)
- **비범위**: 실제 결제/환불 정책, 다국어/다통화 등
- **관련 문서**: [`docs/SRS-summary.md`](docs/SRS-summary.md)

---

## 2) 기능 (MVP 체크리스트)

- [ ] 목록/상세 (페이지네이션, 이미지 캐러셀)
- [ ] 가용성 API (예약/홀드/차단 반영)
- [ ] 임시 홀드 (TTL 후 자동 만료)
- [ ] 예약 확정 (경쟁 시 단 1건만 확정)
- [ ] 마이페이지 (내 예약 조회/취소)
- [ ] 관리자(숙소/요금/차단) CRUD
- [ ] 인증/세션 (이메일+비밀번호)

---

## 3) 기술 스택 (계획)

- **앱**: Next.js + TypeScript, Tailwind CSS, shadcn/ui
- **DB/ORM**: PostgreSQL(Neon/Supabase) + Prisma
- **이미지**: Cloudinary (또는 대체 스토리지)
- **관측/오류**: Sentry
- **테스트**: Vitest(유닛), Playwright(E2E)
- **배포**: Vercel

> 추후 필요해지면 "빠른 시작", "폴더 구조", "로드맵" 섹션을 천천히 추가할 예정입니다.
